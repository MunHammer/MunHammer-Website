Starting a Blog

Written by 2026-08-16

Deciding

  1. I realized that a lot of my search results were from blogs (I use Ecosia), and a fair chunk of my reddit feed was blogs.
  2. These reddit feed blogs were mostly announcements, which I could probably do the same when I have something to showcase.
  3. I started researching blogs, and saw that I can make money off of them (actually all websites, not just blogs).
  4. I decided to not make a blog, because a blog article said that they were a fair amount of work.
  5. Some time passed
  6. I felt like making a blog, and asked my friends, they didn't really care, and I realised I'm basically just looking for a reason at that point
  7. I made a blog

Creating a blog

when creating this blog, I just used my pre-existing website, added some simple TypeScript, HTML, and CSS, and voila! A blog!

The Typescript is pretty simple as well. Basically, I just have my blog page have an extra script in it, which just reads a file that tells it the title of the article, where to link to, and a simple blurb. I then have an html file that that file links to, where I the write the article in.

How this website works

At this point, I'm just padding the post length, as I've already explained this before in my about page
This website uses HTML, CSS, and TypeScript, some quintessential technologies of the world wide web. It stores the HTML in src/page/index.html files, all of the CSS is in the src/styles.css file, and the produced JavaScript files are placed in the same directory as the TypeScript; src/scripts/. The TypeScript is compiled with GitHub actions, just before the website is deployed to GitHub pages.
